# Dúvidas dos dados dos jogos

Lista consolidada (Entrega 20, RockAssistent) do que ficou incerto nos dados embutidos (`assets/data/`) e nos guias
(`content/*/guides/`). Em 07/11/2026 as dúvidas de fato foram decididas pela maioria das fontes, com peso maior para o
Serebii (regra do autor); cada decisão está em [data-decisions.md](data-decisions.md) para o autor conferir. Aqui ficam
só o que nenhuma fonte cobre e as convenções nossas.
