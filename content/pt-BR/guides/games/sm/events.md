## Eventos

Distribuições por Mystery Gift (código, internet, QR). A internet do 3DS foi desligada em 2024: nenhuma delas funciona mais.

| Evento | Ano | Como recebia |
| --- | --- | --- |
| Munchlax com Snorlium Z | 2016 | Mystery Gift pela internet, até 11/01/2017 |
| Magearna | 2016–2017 | QR Code especial, após os créditos |
| Lycanroc | 2017 | código (cartas Guardians Rising) |
| Shiny Tapu Koko | 2017 | internet (Mystery Gift) |
| Salazzle | 2017 | código (cartas) |
| Pikachu com boné do Ash | 2017 | código (filme "I Choose You!") |
| Marshadow | 2017 | código (lojas, filme "I Choose You!") |
| Shiny Silvally | 2017 | código (cartas GX) |
| Celebi | 2017–2018 | código do Gold/Silver do Virtual Console |
| Lendários do "Ano dos Lendários" | 2018 | códigos e internet, um por mês (ex.: Ho-Oh, Reshiram, Zekrom) |
| Decidueye, Incineroar, Primarina | 2018 | Pokémon Bank, com habilidade oculta |
