## Eventos

As distribuições acabaram. O serviço on-line do 3DS foi desligado em abril de 2024; o Mystery Gift pela internet não funciona mais.

| Evento | Ano | Como recebia |
| --- | --- | --- |
| Marshadow | 2017–2018 | Código de série (cinema e lojas) |
| Ano dos Lendários (Pokémon lendário por mês) | 2018 | Códigos de loja (GameStop, Target, GAME) |
| Groudon e Kyogre | 2018 | Código de série |
| Reshiram e Zekrom | 2018 | Código de série |
| Ho-Oh e Lugia | 2018 | Código de série |
| Zeraora | 2018 | Código de série (lojas) |
| Magearna | desde 2016 | QR Code oficial, lido no antiquário de Hau'oli City após o título |
| Global Missions | 2017–2018 | Internet (itens e Festival Coins) |

- O QR Code do Magearna ainda funciona porque é lido no próprio jogo.
- Pokémon antigos chegavam pelo Pokémon Bank; hoje o caminho é o Pokémon HOME (só ida).
