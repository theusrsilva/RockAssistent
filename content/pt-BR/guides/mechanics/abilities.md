## O que são

- Existem desde a Gen 3. Cada Pokémon tem uma habilidade ativa.
- Cada espécie tem 1 ou 2 habilidades comuns e, desde a Gen 5, pode ter uma habilidade oculta (Hidden Ability, HA).
- Com 2 comuns, qual delas sai é sorteado na captura.
- LGPE e Legends: Arceus não usam habilidades em batalha.

## Exemplos marcantes

| Habilidade | Efeito |
| --- | --- |
| Levitate | Imune a golpes Ground |
| Intimidate | Baixa o Attack do oponente ao entrar |
| Wonder Guard | Só golpes super efetivos acertam (Shedinja) |
| Huge Power / Pure Power | Dobra o Attack |
| Drought / Drizzle / Sand Stream / Snow Warning | Clima ao entrar (5 turnos desde a Gen 6) |
| Speed Boost | +1 Speed por turno |
| Protean / Libero | Muda o tipo para o do golpe (uma vez por entrada desde a Gen 9) |
| Multiscale | Metade do dano com HP cheio |
| Regenerator | Cura 1/3 ao sair |

## Habilidade oculta: como obter

| Jogos | Método |
| --- | --- |
| BW, B2W2 | Pokémon Dream World (online, encerrado); Hidden Grottoes (B2W2) |
| XY | Friend Safari; hordas (algumas espécies) |
| ORAS | DexNav (chance cresce com a cadeia) |
| SM, USUM | Chamadas de ajuda (SOS), a partir da cadeia 11 |
| SwSh | Max Raid Battles (4 e 5 estrelas); Dynamax Adventures |
| SV | Tera Raids (4 estrelas para cima, em parte das espécies); Ability Patch |
| Breeding | Pais com HA passam (ver [Breeding](/guias/mechanics/breeding/breeding)) |

## Trocando de habilidade

| Item | Efeito | Jogos |
| --- | --- | --- |
| Ability Capsule | Troca entre as 2 comuns | Gen 6+ |
| Ability Patch | Comum → oculta (SV: também oculta → comum) | SwSh (Crown Tundra), SV |

- Ability Capsule não funciona em espécie com uma só habilidade comum.
- Onde achar: lojas de BP, raids e recompensas de pós-jogo.

## Efeitos fora da batalha (líder do time)

| Habilidade | Efeito |
| --- | --- |
| Synchronize | Selvagem com a mesma natureza (ver [Naturezas](/guias/mechanics/natures/natures)) |
| Cute Charm | 2/3 de chance de selvagem do gênero oposto |
| Static / Magnet Pull | Mais encontros de Electric / Steel |
| Flash Fire, Storm Drain, Lightning Rod etc. | Mais encontros do tipo ligado (SwSh) |
| Intimidate / Keen Eye | Menos encontros de nível baixo |
| Stench / White Smoke / Quick Feet | Menos encontros |
| Arena Trap / Illuminate / No Guard | Mais encontros |
| Sticky Hold / Suction Cups | Mais fisgadas na pesca |
| Compound Eyes / Super Luck | Selvagens com item segurado mais vezes |
| Flame Body / Magma Armor / Steam Engine | Ovos chocam na metade do tempo |
| Pickup / Honey Gather | Achar itens depois das batalhas |
