## Métodos

| Método | Exemplo |
| --- | --- |
| Nível | Charmander → Charmeleon (nv. 16) |
| Pedra ou item usado | Pikachu + Thunder Stone → Raichu |
| Troca | Kadabra → Alakazam |
| Troca segurando item | Onix + Metal Coat → Steelix |
| Felicidade | Golbat → Crobat |
| Felicidade + hora | Eevee → Espeon (dia) / Umbreon (noite) |
| Item segurado + hora (subir de nível) | Sneasel + Razor Claw à noite → Weavile |
| Golpe conhecido | Piloswine com Ancient Power → Mamoswine |
| Local | Magneton em campo magnético → Magnezone (Gen 4–7) |
| Companheiro no time | Mantyke com Remoraid → Mantine |
| Clima | Sliggoo na chuva → Goodra |
| Gênero | Kirlia ♂ + Dawn Stone → Gallade |
| Versão ou hora do jogo | Rockruff → Lycanroc (dia/noite/entardecer) |
| Ação acumulada | Primeape usa Rage Fist 20× → Annihilape (SV) |
| Passos (Let's Go) | Pawmo, Bramblin, Rellor: 1.000 passos fora da Poké Ball (SV) |

- Everstone segurado impede a evolução. Na tela de evolução, B cancela (menos por item usado).
- Legends: Arceus e SV: Linking Cord substitui a troca. Z-A: as evoluções por troca também têm alternativa no jogo.

## Outros itens

- Segurar e subir de nível: Oval Stone (Happiny, dia), Razor Claw (Sneasel, noite), Razor Fang (Gligar, noite).
- Usar: Tart Apple/Sweet Apple (Applin), Cracked Pot (Sinistea), Galarica Cuff/Wreath (Galarian Slowpoke),
  Black Augurite (Scyther → Kleavor), Peat Block (Ursaring → Ursaluna, lua cheia), Auspicious/Malicious Armor
  (Charcadet), Metal Alloy (Duraludon → Archaludon), Syrupy Apple (Applin → Dipplin), Unremarkable/Masterpiece Teacup
  (Poltchageist).
