## What they are

- Introduced in Gen 3. Each Pokémon has one active Ability.
- Each species has 1 or 2 regular Abilities and, since Gen 5, may have a Hidden Ability (HA).
- With 2 regular ones, which one you get is rolled at the encounter.
- LGPE and Legends: Arceus do not use Abilities in battle.

## Notable examples

| Ability | Effect |
| --- | --- |
| Levitate | Immune to Ground moves |
| Intimidate | Lowers the foe's Attack on entry |
| Wonder Guard | Only super effective moves hit (Shedinja) |
| Huge Power / Pure Power | Doubles Attack |
| Drought / Drizzle / Sand Stream / Snow Warning | Weather on entry (5 turns since Gen 6) |
| Speed Boost | +1 Speed every turn |
| Protean / Libero | Changes type to the move's type (once per entry since Gen 9) |
| Multiscale | Half damage at full HP |
| Regenerator | Heals 1/3 on switching out |

## Hidden Ability: how to get it

| Games | Method |
| --- | --- |
| BW, B2W2 | Pokémon Dream World (online, closed); Hidden Grottoes (B2W2) |
| XY | Friend Safari; hordes (some species) |
| ORAS | DexNav (chance grows with the chain) |
| SM, USUM | SOS calls, from chain 11 on |
| SwSh | Max Raid Battles (4 and 5 stars); Dynamax Adventures |
| SV | Tera Raids (4 stars and up, for part of the species); Ability Patch |
| Breeding | Parents with the HA pass it (see [Breeding](/guias/mechanics/breeding/breeding)) |

## Changing the Ability

| Item | Effect | Games |
| --- | --- | --- |
| Ability Capsule | Swaps between the 2 regular ones | Gen 6+ |
| Ability Patch | Regular → hidden (SV: also hidden → regular) | SwSh (Crown Tundra), SV |

- The Ability Capsule does not work on a species with only one regular Ability.
- Where to find them: BP shops, raids and postgame rewards.

## Field effects (party lead)

| Ability | Effect |
| --- | --- |

| Static / Magnet Pull | More Electric / Steel encounters |

| Intimidate / Keen Eye | Fewer low-level encounters |
| Stench / White Smoke / Quick Feet | Fewer encounters |
| Arena Trap / Illuminate / No Guard | More encounters |
| Sticky Hold / Suction Cups | More bites when fishing |
| Compound Eyes / Super Luck | Wild Pokémon hold items more often |
| Flame Body / Magma Armor / Steam Engine | Eggs hatch in half the time |
| Pickup / Honey Gather | Find items after battles |
