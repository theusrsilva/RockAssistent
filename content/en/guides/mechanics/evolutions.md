## Methods

| Method | Example |
| --- | --- |
| Level | Charmander → Charmeleon (lv. 16) |
| Stone or used item | Pikachu + Thunder Stone → Raichu |
| Trade | Kadabra → Alakazam |
| Trade holding an item | Onix + Metal Coat → Steelix |
| Friendship | Golbat → Crobat |
| Friendship + time | Eevee → Espeon (day) / Umbreon (night) |
| Held item + time (level up) | Sneasel + Razor Claw at night → Weavile |
| Known move | Piloswine with Ancient Power → Mamoswine |
| Location | Magneton in a magnetic field → Magnezone (Gen 4–7) |
| Party member | Mantyke with Remoraid → Mantine |
| Weather | Sliggoo in the rain → Goodra |
| Gender | Male Kirlia + Dawn Stone → Gallade |
| Version or in-game time | Rockruff → Lycanroc (day/night/dusk) |
| Accumulated action | Primeape uses Rage Fist 20× → Annihilape (SV) |
| Steps (Let's Go) | Pawmo, Bramblin, Rellor: 1,000 steps outside the Poké Ball (SV) |

- A held Everstone stops evolution. On the evolution screen, B cancels it (except for used items).
- Legends: Arceus and SV: the Linking Cord replaces trading. Z-A: trade evolutions also have an in-game alternative.

## Odd cases

- Nincada → Ninjask + Shedinja (free slot and a Poké Ball, Gen 4+).
- Tyrogue → Hitmonlee/Hitmonchan/Hitmontop depending on Attack × Defense.
- Inkay → Malamar with the console upside down (Gen 6–7).
- Pancham → Pangoro with a Dark-type Pokémon in the party.
- Gimmighoul → Gholdengo with 999 Gimmighoul Coins (SV).
