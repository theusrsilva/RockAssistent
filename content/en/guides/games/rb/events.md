- **Mew** was the only event Pokémon: handed out at Nintendo events by direct trade (Lv. 5).
- No Mystery Gift or event key items in this generation.
- 3DS Virtual Console (2016): Mew Lv. 5 by eShop code and in stores, Japan only; no distribution elsewhere.
