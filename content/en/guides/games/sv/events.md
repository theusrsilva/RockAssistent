## How they were received

- **Mystery Gift** (Poké Portal menu): via internet or code.
- **Event Tera Raids**: special crystals on the map during the event (5★ and 7★); you need internet to download Poké Portal News.
- Most distributions have ended; raids come back from time to time as reruns.

## Main distributions

| Event | Year | How |
| --- | --- | --- |
| Pikachu with Flying Tera Type | 2022–2023 | Mystery Gift via internet (game bought by Feb 2023) |
| 7★ Charizard (Tera Dragon) | 2022–2023 | Event Tera Raid (with reruns) |
| 7★ starters from other generations (Cinderace, Greninja, Decidueye, Samurott, Typhlosion, Inteleon, Chesnaught, Delphox, Rillaboom, Primarina, Emboar, Sceptile, Blaziken, Swampert...) | 2023–2024 | Event Tera Raid, one at a time |
| Walking Wake and Iron Leaves | 2023 | Event 5★ Tera Raid (Walking Wake in Scarlet, Iron Leaves in Violet) |
| Mew (random Tera Type) | 2023 | Mystery Gift by code, alongside the Mewtwo event |
| 7★ Mewtwo (Tera Psychic) | 2023 | Event Tera Raid |
| Mythical Pecha Berry (unlocks Pecharunt) | 2024 | Mystery Gift via internet (Mochi Mayhem epilogue) |
| World Championship (VGC) Pokémon | 2023–2024 | Mystery Gift by code |
| Shiny Rayquaza, shiny Glimmora and other guaranteed-shiny raids | 2024 | Event 5★ Tera Raid (to be confirmed) |

- A 7★ raid Pokémon can only be caught once per save file and comes with the Mightiest Mark.
- There were also gifts for linking Pokémon HOME and Pokémon GO (Gimmighoul in Roaming Form).
