| --- | --- | --- |
| Munchlax with Snorlium Z | 2016 | early purchase code |
| Magearna | 2016–2017 | special QR Code, after the credits |
| Lycanroc | 2017 | code (Guardians Rising cards) |
| Shiny Tapu Koko | 2017 | internet (Mystery Gift) |
| Salazzle | 2017 | code (cards) |
| Pikachu with Ash's cap | 2017 | code ("I Choose You!" movie) |
| Marshadow | 2017 | code (stores, "I Choose You!" movie) |
| Shiny Silvally | 2017 | code (GX cards) |
| Celebi | 2017–2018 | code from the Virtual Console Gold/Silver |
| "Year of Legendary Pokémon" legendaries | 2018 | codes and internet, one per month (e.g. Ho-Oh, Reshiram, Zekrom) |
| Decidueye, Incineroar, Primarina | 2018 | Pokémon Bank, with Hidden Ability |
